# Epistula 1.0.0

Epistula's first public release contains the complete PostgreSQL mail system:
Postfix delivery and administration, implicit-TLS IMAP, a scoped HTTP API,
optional model annotation and archive classification, and an MCP connector.

The repository starts with a file-by-file introduction to the 1.0 implementation.
Future changes are recorded in focused commits. Engineering design notes are
included alongside source and regression tests.

Each platform archive includes all five Epistula executables. Linux DEB/RPM
packages install dedicated service accounts and preserve edited configuration
without enabling or starting services. Packages and the checksum manifest are
signed with the published OpenPGP release key; GitHub provides build attestations.

Follow the README for a new installation and docs/releases.md for download
verification. Configure PostgreSQL, Postfix, filesystem access, TLS, and API tokens
before enabling components. Archive sorting and Trash purge are opt-in.

The optional MCP connector has offline mock integration coverage. A live API/token
acceptance check remains an operator task. Blob-only recovery cannot recover
PostgreSQL-only mailbox state; coordinated backups remain necessary.
