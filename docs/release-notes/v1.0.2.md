# Epistula 1.0.2

Epistula 1.0.2 corrects API problem-document identifiers when one API instance
is published through more than one reverse-proxy virtual host.

- `application/problem+json` responses now use root-relative
  `/mail/api/errors/<type>` identifiers. Clients resolve them under the public
  host that handled the request, while the API avoids reflecting an untrusted
  `Host` header.
- The model annotation worker recognizes the relative annotation-queue problem
  type and no longer accepts the old placeholder type.

No schema or configuration changes are required. Deploy the API before
restarting the model annotation worker; the database, IMAP, and MCP components
are unchanged apart from the coordinated release build.

See the [changelog](https://github.com/ptudor/epistula-mail/blob/v1.0.2/CHANGELOG.md)
for the recorded changes and the
[release guide](https://github.com/ptudor/epistula-mail/blob/v1.0.2/docs/releases.md)
for archive, package, signature, and build-attestation verification.
